# 激光打印机 LP-4500 产品手册

## 一、产品概述

LP-4500 是面向中小办公室的黑白激光打印机，标称打印速度 45 页/分钟，支持 A4/A5 自动双面，标配 550 页纸盒与 100 页旁路进纸，月打印负荷建议不超过 8 万页。

## 二、整机参数

| 项目 | 参数 |
| --- | --- |
| 打印速度 | 45 页/分钟（A4 单面） |
| 首页输出时间 | ≤ 6.5 秒 |
| 分辨率 | 1200 × 1200 dpi |
| 内存 | 1 GB，可扩展至 2 GB |
| 接口 | USB 2.0 / 千兆网口 |
| 双面打印 | 支持自动双面 |
| 纸张容量 | 550 页纸盒 + 100 页旁路 |
| 月负荷 | 建议 ≤ 80,000 页 |
| 整机尺寸 | 420 × 430 × 320 mm |
| 重量 | 21.5 kg |

## 三、耗材与寿命

| 耗材 | 型号 | 标称印量 | 说明 |
| --- | --- | --- | --- |
| 原装硒鼓 | CR-4500 | 12,000 页 | 5% 覆盖率 |
| 兼容硒鼓 | CR-4500C | 8,000 页 | 第三方兼容件 |
| 维护套件 | MK-01 | 每 20 万页 | 含定影膜与搓纸轮 |
| 废粉仓 | WF-4500 | 每 5 万页 | 需与硒鼓同步检查 |

印量按 ISO/IEC 19752 标准、5% 覆盖率测算，实际印量随文档覆盖率变化。覆盖率 10% 时，原装硒鼓实际印量约为标称值的 55%。

## 四、驱动与部署

1. 访问公司内网驱动目录下载 LP-4500 通用驱动（Windows / macOS 均有）。
2. 网络部署建议固定 IP，避免 DHCP 续租导致脱机。
3. 批量部署可用打印管理工具推送，单台设备建议不超过 50 个并发队列。
4. 首次安装后打印配置页，核对固件版本与网络参数。

## 五、日常维护

- 每 5,000 页清理一次纸粉与转印区域；
- 出现纵向黑线时检查硒鼓感光鼓表面是否划伤；
- 卡纸后必须完整取出纸张，禁止暴力拉扯，避免残留碎片；
- 长期停用应取出硒鼓，避光密封保存。

## 六、能耗与噪音

待机功耗 ≤ 8 W，打印功耗 ≤ 620 W，休眠唤醒时间约 4 秒。工作噪音 ≤ 56 dB(A)，建议与工位保持 1.5 米以上距离。
